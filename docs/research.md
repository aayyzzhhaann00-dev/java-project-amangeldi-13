Research — Beeline Kazakhstan Billing System
Орындаған: Амангелді Аяжан

1. Ұйым туралы
Beeline Kazakhstan — Қазақстандағы мобильді байланыс және интернет қызметтерін ұсынатын компания. Компания абоненттерге әртүрлі тарифтер мен байланыс қызметтерін ұсынады. Бұл жобада абоненттердің тарифтерін, балансын және төлемдерін басқару жүйесі қарастырылады.

3. Анықталған проблема
Абонент интернет пен қоңырауларға қанша ақша жұмсағанын, ал жүйе қанша төлем алынуы керектігін дұрыс анықтауы керек. Мәліметтер дұрыс есептелмесе, төлем сомасы да қате шығуы мүмкін.

3. Ұсынылатын шешім
Java тілінде Billing System жүйесін жасау. Жүйе абоненттің тарифін, балансын және пайдаланған қызметтерін байланыстырып, төлем сомасын автоматты түрде есептейді. Төлем алдында балансты тексеріп, төлем сәтті болса, түбіртек қалыптастырады.

Қарапайым тілмен: Бағдарлама интернет пен қоңырауларға кеткен ақшаны өзі есептеп, абонентке қанша төлеу керектігін көрсетеді. Егер баланста ақша жеткіліксіз болса, ескерту шығарады.

5. Жобаның мақсаты
Абоненттердің тарифтерін, балансын және төлемдерін автоматты түрде есептеп, басқаруға мүмкіндік беретін қарапайым Java жүйесін жасау.

7. Жобаның міндеттері
Абоненттерді тіркеу;
Абонент туралы ақпаратты сақтау;
Тарифтерді таңдау және басқару;
Балансты тексеру және толықтыру;
Пайдаланылған интернет пен қоңыраулардың құнын есептеу;
Төлем сомасын анықтау;
Төлем шотын қалыптастыру;
Төлем тарихын сақтау;
Баланс жеткіліксіз болған жағдайда ескерту шығару;
Жүйені тестілеу.

11. Күтілетін нәтиже
Нәтижесінде абоненттерді тіркеуге, тарифтерді басқаруға, балансты тексеруге, пайдаланылған қызметтердің құнын есептеуге және төлем шотын қалыптастыруға мүмкіндік беретін Java бағдарламасы дайындалады.
