Research — Beeline Kazakhstan Billing System

Орындаған: Амангелді Аяжан

1. Ұйым туралы

Beeline Kazakhstan — Қазақстандағы мобильді байланыс және интернет қызметтерін ұсынатын компания. Компания абоненттерге әртүрлі тарифтер мен қосымша қызметтер ұсынады.

2. Анықталған проблема

Абоненттердің тарифтері, балансы және пайдаланған қызметтері бойынша төлемдерді дұрыс есептеу және бақылау қажеттілігі. Қолмен есептеу кезінде қателіктер болуы мүмкін.

3. Ұсынылатын шешім

Java тілінде Billing System жүйесін әзірлеу. Жүйе абоненттердің балансын тексеріп, тариф пен қосымша қызметтердің құнын автоматты түрде есептеп, төлем шотын қалыптастырады.

4. Жобаның мақсаты

Абоненттердің тарифтері мен төлемдерін автоматты түрде есептейтін және басқаратын ақпараттық жүйе құру.

5. Жобаның міндеттері

1. Абоненттерді тіркеу және олардың ақпаратын сақтау.
2. Тарифтерді таңдау және басқару.
3. Абонент балансын тексеру және толықтыру.
4. Пайдаланылған қызметтердің құнын есептеу.
5. Жалпы төлем сомасын автоматты түрде шығару.
6. Төлем шотын қалыптастыру.
7. Төлемдер тарихын сақтау.
8. Жүйенің жұмысын тестілеу.

6. Қолданылатын техникалар мен технологиялар

* Java — бағдарламаны әзірлеу.
* IntelliJ IDEA — код жазу ортасы.
* OOP — объектіге бағытталған бағдарламалау.
* ArrayList, HashMap — мәліметтерді сақтау және басқару.
* Exception Handling — қателерді өңдеу.
* File Handling — ақпаратты файлға сақтау.
* JUnit — бағдарламаны тестілеу.
* GitHub — жобаны сақтау.

7. Күтілетін нәтиже

Java тілінде жұмыс істейтін Billing System бағдарламасы жасалады. Бағдарлама абоненттерді тіркеуге, тарифтерді басқаруға, балансты тексеруге, төлемдерді автоматты есептеуге және төлем тарихын сақтауға мүмкіндік береді.
