Research — Beeline Kazakhstan Billing System
Орындаған: Амангелді Аяжан
1. Ұйым туралы
Beeline Kazakhstan — Қазақстандағы ұялы байланыс және интернет қызметтерін ұсынатын компания. Компания абоненттерге түрлі тарифтер мен байланыс қызметтерін ұсынады.
2. Анықталған проблема
Абонентке пайдаланған интернеті мен қоңыраулары үшін қанша төлем жасау керектігін және балансында қанша ақша қалғанын бақылау қажет.
Қарапайым тілмен: Абонент қанша ақша жұмсағанын, қанша төлеуі керектігін және балансында қанша ақша қалғанын білуі керек.
3. Ұсынылатын шешім
 Бағдарлама интернет пен қоңырауларға кеткен ақшаны өзі есептеп, абонентке қанша төлеу керектігін көрсетеді.
4. Жобаның мақсаты
Абоненттердің тарифтері мен төлемдерін басқаруға арналған Java бағдарламасын жасау.
5. Жобаның міндеттері
Абоненттерді тіркеу;
Абонент туралы ақпаратты сақтау;
Тарифтерді басқару;
Балансты тексеру және толықтыру;
Қызметтердің құнын есептеу;
Төлем сомасын анықтау;
Төлем түбіртегін қалыптастыру;
Төлем тарихын сақтау;
Бағдарламаны тестілеу.
6. Қолданылатын техникалар мен технологиялар
Java — бағдарламалау тілі;
IntelliJ IDEA — бағдарламалау ортасы;
OOP — объектіге бағытталған бағдарламалау;
ArrayList, HashMap — ақпаратты сақтау;
Exception Handling — қателерді өңдеу;
File Handling — файлмен жұмыс;
JUnit 5 — бағдарламаны тестілеу;
GitHub — жобаны сақтау.
7. Күтілетін нәтиже
 Абонент қанша ақша жұмсағанын, қанша төлеу керектігін және қанша ақшасы қалғанын бағдарлама арқылы көре алады.
