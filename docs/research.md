Research — Beeline Kazakhstan Billing System
Орындаған: Амангелді Аяжан
1. Жобаның сипаттамасы
Beeline Kazakhstan — мобильді байланыс және интернет қызметтерін ұсынатын компания. Жоба абоненттердің тарифтері мен төлемдерін басқаруға арналған.
2. Проблемасы
Абоненттердің тарифін, балансын және пайдаланған қызметтерінің ақысын дұрыс есептеу және бақылау қажеттілігі.
3. Шешу жолы
Java тілінде төлемдерді автоматты есептейтін жүйе жасау. Жүйе балансты тексереді, тариф құнын есептейді және төлем шотын шығарады.
4. Жүйенің пайдаланушылары
Абонент: балансын және тарифін қарайды.
Әкімші: абоненттер мен тарифтерді басқарады.
Жүйе: төлемдерді автоматты есептейді.
5. Функционалдық талаптар
Абонентті тіркеу.
Тариф таңдау.
Балансты тексеру.
Балансты толықтыру.
Қызметтер шығынын есептеу.
Төлем сомасын шығару.
Төлем тарихын сақтау.
Төлем шотын қалыптастыру.
6. Қандай технологиялар қолданылады?
Java — бағдарлама жазу.
OOP — кластармен жұмыс істеу.
ArrayList, HashMap — ақпарат сақтау.
Exception Handling — қателерді өңдеу.
File Handling — файлға мәлімет сақтау.
JUnit — тестілеу.
GitHub — жобаны сақтау.

Бұл жобада олардың мобильді байланыс қызметтерін басқару принциптері қарастырылады.
10. Ақпарат көздері
Жобаның мақсаты: абоненттердің тарифтері мен төлемдерін автоматты түрде есептейтін қарапайым Java жүйесін жасау.
