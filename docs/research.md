Research — Beeline Kazakhstan Billing System

Орындаған: Амангелді Аяжан

1. Ұйым туралы

Beeline Kazakhstan — Қазақстандағы мобильді байланыс және интернет қызметтерін ұсынатын компания. Компания абоненттерге әртүрлі тарифтер мен қосымша қызметтер ұсынады. Жобада абоненттердің тарифтері мен төлемдерін басқару процесі қарастырылады.

2. Анықталған проблема

Абоненттердің тарифтері, балансы және пайдаланған қызметтері туралы ақпаратты бір жүйеде тиімді басқару қажеттілігі.

3. Ұсынылатын шешім

Java тілінде абоненттердің тарифтері, балансы және пайдаланған қызметтері туралы ақпаратты бір жерде сақтап, басқаруға мүмкіндік беретін Billing System бағдарламасын әзірлеу.

4. Жобаның мақсаты

Абоненттердің тарифтерін, балансын және төлемдерін басқаруға арналған ақпараттық жүйе құру.

5. Жобаның міндеттері

1. Абоненттерді тіркеу және ақпараттарын сақтау.
2. Тарифтерді таңдау және басқару.
3. Абонент балансын тексеру және толықтыру.
4. Пайдаланылған қызметтер туралы ақпаратты сақтау.
5. Қызметтердің құнын есептеу.
6. Төлем шотын қалыптастыру.
7. Төлемдер тарихын сақтау.
8. Жүйенің жұмысын тестілеу.

6. Қолданылатын техникалар мен технологиялар

* Java — бағдарламаның негізгі кодын жазу.
* IntelliJ IDEA — бағдарламалау ортасы.
* OOP — бағдарламаны кластарға бөлу.
* ArrayList, HashMap — мәліметтерді сақтау және басқару.
* Exception Handling — қателерді өңдеу.
* File Handling — ақпаратты файлға сақтау.
* JUnit 5 — бағдарламаны тестілеу.
* GitHub — жобаның кодын сақтау.

7. Күтілетін нәтиже

Java тілінде жұмыс істейтін Billing System бағдарламасы жасалады. Жүйе абоненттер туралы ақпаратты сақтауға, тарифтерді басқаруға, балансты тексеруге, пайдаланылған қызметтерді есепке алуға және төлем шотын қалыптастыруға мүмкіндік береді.
